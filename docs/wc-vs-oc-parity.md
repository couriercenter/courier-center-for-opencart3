# Courier Center: WooCommerce 1.6.0 ↔ OpenCart 3 / OpenCart 4 1.1.0: πίνακας ισοδυναμίας

Έλεγχος 2026-10-12: ο κώδικας του WooCommerce (main `f279e28`, v1.6.0) διαβάστηκε αρχείο προς αρχείο και συγκρίθηκε με το OpenCart 3 και 4. Όπου ήταν δυνατό η σύγκριση έγινε και με εκτέλεση του κώδικα (π.χ. οι σταθμοί/υπηρεσίες ανά ΤΚ: 90.000 ΤΚ και 1,1 εκατ. συνδυασμοί, 0 διαφορές).

Σύμβολα: ✅ ίδιο · 🔧 διορθώθηκε σε αυτόν τον γύρο · ➕ το OpenCart έχει κάτι παραπάνω · ⚙️ διαφορά που επιβάλλει η πλατφόρμα

## Άλλες διαφορές (σκόπιμες)
- ➕ Το ΤΚ με κενό («106 71») γίνεται δεκτό στο OpenCart (στο WooCommerce απορρίπτεται).
- ➕ Η μαζική δημιουργία μπλοκάρει BOX NOW + αντικαταβολή πριν καλέσει το API.
- ⚙️ Το «cron χωρίς cron job» χρειάζεται να επιτρέπει ο server αιτήματα προς τον ίδιο το site· αλλιώς ισχύει η εντολή cron / URL.
- ⚙️ Στο OpenCart το πακέτο OC3 δεν έχει ακόμα δικό του repo/ενημερώσεις GitHub (θα γίνει με το release).
